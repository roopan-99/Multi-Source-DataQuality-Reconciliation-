# 📊 Multi-Source Data Quality & Reconciliation

> Transforming raw data into clean, reliable, and meaningful information using Microsoft Excel and SQL.

---

## 📌 About This Project

This project focuses on validating, cleaning, and analyzing business data collected from multiple departments. It demonstrates how Excel and SQL can be used together to improve data quality, identify inconsistencies, and generate accurate reports for business decision-making.

---

## 🔍 What This Project Covers

✔️ Data Cleaning

✔️ Data Validation

✔️ Duplicate Record Detection

✔️ Missing Value Analysis

✔️ Data Standardization

✔️ SQL Queries for Reporting

✔️ Department-wise Analysis
